# ✋ AI Hand Gesture Controller

An AI-powered hand gesture recognition system that detects hand gestures in real time using a webcam and converts them into keyboard actions.

## 🚀 Features

- Real-time hand tracking
- Custom gesture recognition
- 99.18% Model Accuracy
- Keyboard automation
- Machine Learning based prediction
- Live webcam inference

## 🛠️ Tech Stack

- Python
- OpenCV
- MediaPipe
- Scikit-learn
- NumPy
- Pandas
- PyAutoGUI

## 📂 Project Structure

AI-Hand-Gesture-Controller/
│── Dataset/
│── models/
│── trainer/
│── utills/
│── app.py

## ▶️ Run

```bash
pip install -r requirements.txt
python app.py
```
